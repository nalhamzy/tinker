Help with creating, saving and sharing your little apps.

How do I start?

Open one of the four included examples, or use Create to describe a tool or game. Generation needs internet and an available cloud allowance or your own API key. No coding experience is required.

Does it work offline?

Saved applets run locally without another AI request. Creating or editing with AI needs internet. Some phone capabilities depend on device support, permissions or online system services.

Why is the workshop taking time?

It builds and checks generated HTML. A request can take several minutes. With Cloud workshop enabled, you can return to the shelf later. With your own key in direct mode, keep Tinker open. If the job fails, use a focused request and retry; cloud charges for failed jobs are refunded as credit units.

What does it cost?

The cloud workshop includes a monthly allowance of 15 units: a creation uses 3 and an edit uses 1. Saved applets do not consume generation allowance when opened. Purchases are unavailable in this release. Your AI provider's charges still apply if you use your own API key.

Can I send an app to a friend?

Use Share a copy from the applet menu to export HTML. Browser support varies, and phone-only features may not work outside Tinker. The copy excludes the applet's separate saved state; data embedded in the HTML remains included.

A phone feature is unavailable

Open the applet's permissions menu and your device permission settings. A feature may require compatible hardware or a system service. You can keep using other functions when permission is denied.

Delete data or request cloud deletion

To remove a local applet, delete it from your shelf. To remove your own API key, use Settings. These actions do not automatically erase cloud identity, credits or usage records.

For cloud data, use Settings → Privacy & support → Delete cloud data & identity. This removes cloud jobs, reports, credits and usage records along with the anonymous identity, while keeping local applets. For help or deletion of support messages, email nalhamzy@gmail.com with the subject “Tinker data deletion request”. Include the cloud identity or job reference if available, and the approximate request date. We may ask for information needed to verify which records belong to you. Never send an API key, password or private applet files.

Job records also follow the cleanup process described in the privacy policy. Provider logs and backups may have separate retention.

Tell us what happened

For a problem or inappropriate AI output, describe the screen, your app version and what you expected. Share a screenshot only if it contains no private information. Use Settings → Privacy & support → Report AI content to send a report without leaving the app. Email support below for other help.
